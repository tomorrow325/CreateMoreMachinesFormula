# run-tier Specification

## Purpose

定义玩家手动调整机器「运行等级」（配方优先级）的行为：扳手交互与循环规则、准入与择优两个生效面、存储与持久化语义、可调机器名单，以及工程师护目镜的显示规则。运行等级不改变机器的出厂等级，也不影响处理速度与并行数。

## Requirements

### Requirement: 扳手循环调整运行等级

手持 Create 扳手对受支持机器**普通右键**（非潜行）时，系统 SHALL 把该机器的运行等级调整为下一档：可调范围为 `0 .. 出厂等级`（只能调低、不能调高），循环到底后回到出厂等级；调整成功时 SHALL 在动作栏提示「配方优先已被调整为：X」并播放扳手转动音效，且消费掉该次右键。无可调空间（0 级机器）时 MUST NOT 产生任何写入、提示或音效。

#### Scenario: 普通分级机器逐档下调

- **WHEN** 对末影级（3 级）机器依次普通右键扳手
- **THEN** 运行等级按 3 → 2 → 1 → 0 → 3 循环，每次均有动作栏提示与音效

#### Scenario: 零级机器无反馈

- **WHEN** 对原版 Create 机器（0 级）普通右键扳手
- **THEN** 不写入运行等级、无提示、无音效，右键不被消费

#### Scenario: 潜行右键不触发

- **WHEN** 玩家潜行状态下持扳手右键受支持机器
- **THEN** 不调整运行等级，事件不处理

### Requirement: 创造级机器的循环与准入例外

创造级机器 SHALL 参与循环且顺序为 `4 → 3 → 2 → 1 → 0 → 创造 → 4`，但其**准入等级恒为创造级**：无论运行等级调到哪档，创造机器都能执行一切配方；手动值只影响其择优偏好（优先挑贴近该档的配方）。

#### Scenario: 创造机器调档不收缩准入

- **WHEN** 创造级机器被调到运行等级 1（黄铜）后处理 `Tier.BEYOND` 门槛配方
- **THEN** 准入仍被允许（创造机器通行一切），只是同输入多条配方时优先挑黄铜档

### Requirement: 运行等级的双生效面

运行等级 SHALL 同时作用于两个层面：**准入**（做不了高于该档的配方，未设置时等于出厂等级）与**择优**（同一输入的多个配方里优先挑贴近该档的那条，见 `machine-gates` 的择优需求）。运行等级 MUST NOT 影响处理速度与并行数（两者只读出厂等级）。

#### Scenario: 调低后拒绝高门槛配方

- **WHEN** 末影级机器运行等级被调到 1，随后处理 `Tier.END` 门槛配方
- **THEN** 准入被拒绝，如同机器只有黄铜级

#### Scenario: 速度与并行不变

- **WHEN** 分级机器的运行等级被调整
- **THEN** 其处理速度与并行数与调整前完全一致

### Requirement: 存储与生命周期语义

运行等级 SHALL 以独立于出厂等级的数据形式随方块实体持久化（写入存档 NBT、随区块同步到客户端）：默认**未设置**（等同出厂等级，旧存档加载后行为完全不变）；机器被破坏后该设置随之丢失。玩家手动设成与出厂等级相同的值 SHALL 与「未设置」可区分（护目镜显示手动值）。

#### Scenario: 旧存档不受影响

- **WHEN** 加载从未调整过运行等级的旧存档
- **THEN** 所有机器行为与升级前完全一致

#### Scenario: 破坏机器丢设置

- **WHEN** 已调整运行等级的机器被破坏并重新放置
- **THEN** 运行等级回到未设置状态

### Requirement: 可调机器名单

运行等级 SHALL 只对名单内的 7 台机器开放：CMM 的机械压机、机械搅拌器、机械手（部署器）、注液器（喷口）、动力锯，以及 CMMM 的分级破碎轮、分级机械锯。名单 SHALL 是唯一来源，扳手调整与护目镜显示共用同一份。破碎轮 SHALL 在玩家点击「轮子」时把运行等级写到配对的「控制器」上（真正执行配方的那半）。CMMM 鼓风机 MUST NOT 入册：本模组未给鼓风处理配方（splashing/haunting/blasting/smoking）装过门槛，登记只会产生无实际效果的假控制；鼓风机自身照常工作。

#### Scenario: 名单外机器不可调

- **WHEN** 持扳手普通右键工作盆、置物台或 CMMM 鼓风机
- **THEN** 不调整运行等级、无提示，右键不被消费

#### Scenario: 点破碎轮写控制器

- **WHEN** 持扳手点击分级破碎轮的「轮子」方块
- **THEN** 运行等级写到配对控制器上，护目镜从任一半都能读到同一值

### Requirement: 护目镜两行显示

戴工程师护目镜查看名单内机器时，系统 SHALL 恒显示两行：「机械等级」（出厂等级）与「运行等级」（当前生效值，未设置时等于出厂等级）；两行相同即表示未被调整过。名单外机器（含原版 Create 机器）MUST NOT 显示这两行。

#### Scenario: 未调整时两行相同

- **WHEN** 护目镜查看从未调整过的末影级机器
- **THEN** 两行均显示「末影」

#### Scenario: 调整后两行不同

- **WHEN** 末影级机器运行等级被调到黄铜后用护目镜查看
- **THEN**「机械等级」显示末影、「运行等级」显示黄铜

#### Scenario: 名单外机器不显示

- **WHEN** 护目镜查看原版 Create 动力辊压机
- **THEN** 不追加「机械等级/运行等级」两行，tooltip 与原版一致
