# Spec Delta

## ADDED Requirements

### Requirement: 同输入多配方按机器等级择优

同一输入命中多条不同门槛的配方时，系统 SHALL 不再沿用「注册顺序第一条」：先按准入等级滤掉机器够不着的候选，再在余下候选中优先选「门槛尽可能贴近但不高于运行等级（择优偏好档）」的那条；高于偏好档的候选整体排在偏好档及以下之后。排序 SHALL 保持稳定：门槛相同时保持 Create 原有的相对偏好（如工作盆按配料数排序）。

#### Scenario: 高门槛机器不再被低门槛配方抢先

- **WHEN** 同一输入同时存在黄铜（1 级）与下界合金（2 级）门槛的配方，2 级机器处理该输入
- **THEN** 机器执行下界合金档配方，而不是注册顺序在前的黄铜档

#### Scenario: 低档机器退而求其次

- **WHEN** 同一输入存在 1 级与 2 级门槛配方，1 级机器处理该输入
- **THEN** 机器执行 1 级配方（2 级被准入滤除）

#### Scenario: 按运行等级贴近优先

- **WHEN** 末影级机器的运行等级被调到黄铜，同一输入存在 0、1、2 级门槛配方
- **THEN** 优先执行 1 级（贴近偏好档）配方

#### Scenario: 创造机器的既有择优保持

- **WHEN** 创造级机器（未手动调整）处理同输入的普通配方与创造专用配方
- **THEN** 创造专用配方优先，其余按门槛降序（与既有行为一致）

### Requirement: 择优覆盖的机器

择优逻辑 SHALL 覆盖：原版与分级破碎轮、原版与 CMM 压机、工作盆类（搅拌、压实等）、机械锯、磨石。喷口维持其既有的「浇注候选取最严门槛」规则，不引入择优排序。

#### Scenario: 磨石择优后准入一致

- **WHEN** 磨石输入命中多条配方且存在带门槛者
- **THEN** 择优结果仍满足「按最高门槛准入」的既有规则，带门槛配方对 0 级磨石不可达

### Requirement: 机械锯配方下标归零

改变机械锯配方列表的内容与顺序后，系统 SHALL 把随方块实体持久化的配方下标（recipeIndex）归零，保证其恒取「够得着的最高等级」那条，避免沿用旧存档下标取到不同配方。

#### Scenario: 旧存档锯不取错配方

- **WHEN** 带有历史 recipeIndex 的机械锯存档在列表被择优重排后加载
- **THEN** 锁定列表首条（准入内门槛最高者），不因旧下标漂移
